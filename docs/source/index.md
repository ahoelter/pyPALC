# pyPALC

pyPALC optimizes line source arrays with the PALC method (Polar Approximation
of Line source arrays by Curving): it determines the array shape, the
loudspeaker splay angles and the filters for a given venue and loudspeaker.
It is available as a Python package with a command line interface and a
browser-based graphical user interface.
