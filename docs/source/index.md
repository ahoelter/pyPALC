# pyPALC

pyPALC computes the tilt angles of the cabinets of a line source array with
PALC (Polygonal Audience Line Curving), so that the array covers a given
venue, and predicts the sound field of the curved array and of a reference
array. It is a Python package with a command line runner and a GUI that
runs in the browser.

These pages are for Python users: people who run setup files with the
command line, import `pypalc.core` in their own scripts or adapt the GUI.
The GUI itself is explained on its Help page.
